# DocSend

> DocSend is a secure document sharing and analytics platform (now part of Dropbox) used to share sales collateral, pitch decks, and fundraising materials with page-by-page viewer tracking, access controls, and e-signature. DocSend operates a hosted Model Context Protocol (MCP) server secured with OAuth 2.0 (dynamic client registration + PKCE) so agents can access DocSend with mcp:read / mcp:write scopes.

This llms.txt was generated by the API Evangelist enrichment pipeline from the DocSend company profile and the artifacts harvested into this repository. No provider-published /llms.txt was found (HTTP 404).

## Agent access

- [DocSend MCP server](https://mcp.docsend.com/mcp): Hosted Streamable-HTTP MCP endpoint (OAuth-gated, scopes mcp:read / mcp:write)
- [OAuth authorization server metadata](https://docsend.com/.well-known/oauth-authorization-server): RFC 8414 discovery — authorize/token/register/revoke endpoints, PKCE S256
